# Publication and artifact status

The study is available as [arXiv:2609.09702](https://arxiv.org/abs/2609.09702). It is a preprint; no peer-reviewed acceptance is claimed.

This repository includes original formal V6 pipeline source/configuration, result tables, plots, source hashes, and the human-audit protocols from the prepared arXiv source package. Original adjudicated rows, generated input manifests, external MiniMind code, and checkpoints are not bundled. This release does not claim independent end-to-end training reproduction.

Formal V6 (63.9M) results and later 104M development/terminal diagnostics are distinct study stages. See the README and reproduction notes before comparing their numbers.

The project was advised by UIUC faculty. The public preprint lists Xiaofei Feng as sole author. The advisor's name and detailed responsibility split can be added after confirmation.
